## About Me

Identity & Access Management professional focused on Microsoft Entra ID,
Identity Governance, access lifecycle management, and security compliance.

Currently building hands-on Microsoft Entra projects covering user administration,
Conditional Access, MFA, RBAC, authentication, and identity governance while

My background combines cybersecurity operations, identity and physical access
administration, governance, and global business operations.
